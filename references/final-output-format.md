# 最终提示词格式

在教师确认蓝图后，按以下结构生成一份完整、独立的 Markdown 文件。不要把本参考文件的解释文字输出给用户。

## 固定结构

```markdown
# 《课题名称》教学PPT生成提示词

> 使用方法：从“请执行以下任务”开始完整复制给AI PPT工具。

---

# 请执行以下任务

请为……生成……
```

## 逐页规则

1. 页面标题必须表达该页的认知任务或关键结论，避免只写教材小标题。
2. “页面文字”只写实际可上屏内容，不混入对生成工具的解释。
3. “版式与视觉”使用明确布局词，如左右对比、三段流程、中心辐射、逐层缩放、整图高亮。
4. “互动与呈现”仅在确有互动时出现；必须说明先显示什么、何时揭示什么。
5. 教材或用户素材不能自动嵌入时，使用统一占位符；不要生成相似图片冒充原图。
6. 连续页面需要比较时，要求保持相同坐标、尺度、颜色或构图。
7. 关系图必须说明节点、连接方向和重点，不能只写“生成信息图”。

## 下游解析友好规则

- 使用 `#` 表示文档任务，`##` 表示主要区块或页面，`**字段：**` 表示页内信息。
- 使用 `---` 分隔页面。
- 列表缩进保持一致，不在表格单元格内塞入长段自然语言。
- 每页字段顺序保持稳定。
- 不使用HTML、复杂嵌套表格或依赖特定平台的私有语法。
